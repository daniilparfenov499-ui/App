# Danillons Calc

Мобильное приложение для Android: снаружи обычный калькулятор, внутри приватная галерея.
Введи секретный код и нажми `=` — откроется «Danillons Vault».

- Код по умолчанию: **1337** (меняется кнопкой «Код» внутри галереи)
- Фото и видео хранятся только на устройстве, никуда не отправляются
- Галерея закрывается при сворачивании приложения и по кнопке «Назад»
- Содержимое скрыто в списке недавних приложений, скриншоты заблокированы
- Работает офлайн

> Файлы скрыты, но **не зашифрованы**. Удаление приложения или очистка его данных удалит галерею.

## Как получить APK (через GitHub, ничего устанавливать не нужно)

1. Создай репозиторий на github.com и залей туда все файлы (ветка `main`).
2. Открой вкладку **Actions** и дождись зелёной галочки у workflow **Build APK** (3–6 минут).
   Если он не запустился сам: Actions → Build APK → Run workflow.
3. Открой завершённый запуск, внизу в разделе **Artifacts** скачай `DanillonsCalc-apk` (это zip с `DanillonsCalc.apk`).
4. Перенеси `DanillonsCalc.apk` на телефон и открой его. Android попросит разрешить установку из этого источника — разреши.

Чтобы APK автоматически появлялся в Releases, создай тег:

```bash
git tag v1.0 && git push origin v1.0
```

## Структура

```
index.html, css/, js/     веб-часть (калькулятор, галерея)
manifest.webmanifest, sw.js, icons/   PWA-файлы (можно открыть и в браузере)
android/                  Android-оболочка (WebView), проект Gradle
.github/workflows/
  android.yml             сборка APK
  pages.yml               (необязательно) публикация веб-версии на GitHub Pages
```

Веб-часть автоматически копируется в `android/app/src/main/assets/www` перед сборкой.

## Локальная сборка (если есть Android Studio)

Открой папку `android/` в Android Studio и нажми Run. Либо в терминале (нужны JDK 17, Android SDK и Gradle 8.9):

```bash
cd android
gradle assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```
